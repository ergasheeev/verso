# Verso

51 ta mamlakat bo'yicha tahrirlangan sayohat atlasi: viza sharti, valyuta,
eng yaxshi mavsum va favqulodda raqamlar bir joyda.

## Stek

- **Frontend** — React 18, TypeScript, Vite, Tailwind CSS
- **Backend** — Express, Prisma, PostgreSQL (Neon)

## Ishga tushirish

```bash
npm install

# ikkalasi birga
npm run dev

# alohida
npm run dev:frontend
npm run dev:backend
```

## Tuzilishi

```
frontend/   React ilova
```
